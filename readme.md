## Формат файла

Одна строка описывает одну фигуру. Разделитель `;`, дробная часть через точку.

Круг: `CIRCLE;radius`
Прямоугольник: `RECTANGLE;sideA;sideB`

```text
CIRCLE;1.5
RECTANGLE;3;4
```

Регистр типа не важен, пустые строки пропускаются. Запись в файл идёт в том же формате.

## Ошибки при чтении

Если в файле есть неверная строка, он не загружается совсем. Метод `read` выбрасывает `FormatException` с номером строки и причиной, а уже прочитанные фигуры отбрасываются. В `Main` при этом выводится сообщение и бинарный файл не создаётся.

## Исключения

`ParamException` наследует `IllegalArgumentException`, оно непроверяемое. Неверный параметр это ошибка вызывающего кода, поэтому ловить её при каждом создании фигуры не нужно. Конструкторы выбрасывают её при нуле, отрицательных числах, `NaN`, бесконечности и `null` вместо основания цилиндра.

`FormatException` наследует `Exception`, оно проверяемое. Неверный файл это ожидаемая ситуация, поэтому компилятор требует её обработать.

В `Main` при ошибке чтения программа выводит сообщение и завершается. Если высота цилиндра неверная, цилиндр не создаётся, но список всё равно сохраняется.
